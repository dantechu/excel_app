## Trademark Considerations

### Microsoft Trademark Policy

**Official Microsoft Guidelines (https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks):**

| Usage | Allowed? | Notes |
|-------|----------|-------|
| App Name with "Excel" or "Microsoft" | NO | Cannot use trademarks in app name without license |
| Developer Name | NO | Cannot use Microsoft trademarks |
| Screenshots/Icons | NO | Cannot feature Microsoft logos or branding |
| Description (descriptive use) | YES | Can state "teaches Microsoft Excel" |
| Compatibility statements | YES | Can say "for use with Microsoft Excel" |

### App Store Policies

**Apple (Guidelines 2.3.7 & 5.2.1):**
- Cannot pack metadata with trademarked terms
- Cannot use trademarks without permission
- Can result in rejection or removal

**Google Play (Intellectual Property Policy):**
- Prohibits trademark violations
- Apps can be removed for IP violations

### Risk Assessment

| Element | Safe Option | Risk Level if Using "Excel" |
|---------|-------------|----------------------------|
| App Name | Spreadsheet Mastery | HIGH - may be rejected |
| Subtitle/Short Desc | Beginner to Advanced Lessons | MODERATE |
| Keywords | formulas, pivot tables | HIGH - avoid "excel" "microsoft" |
| Description | Mention Excel descriptively | LOW - allowed for educational context |

### Competitor Precedent

Apps like "Tutorial for MS Excel" exist on app stores, suggesting some tolerance for educational apps. However, this doesn't guarantee your app won't be rejected - enforcement varies.

### Recommendations

1. **Safest Approach**: Use "Spreadsheet Mastery" as app name, avoid trademarks in title/keywords
2. **Moderate Risk**: Use "Excel" in subtitle only, safe name
3. **Higher Risk**: Use "Excel Mastery" (similar to existing apps, but risk of rejection)

If rejected, immediately switch to safe alternatives without losing momentum.
